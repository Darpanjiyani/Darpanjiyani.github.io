Multi-agent text-to-SQL

AI Data Agent

Ask a data question in plain English and get the answer, a chart and the exact SQL. Three layers of checks keep the database read-only.

question→Claude router→SQL agent or pandas ETL agent→sqlglot guard + LLM judge→PostgreSQL (read-only)

Live demo ↗GitHub ↗How I built it →

Build detailsHide details
  • Built a LangGraph multi-agent system where Claude routes plain-English questions to a SQL agent or a pandas ETL agent
  • Raised text-to-SQL execution accuracy from 89.4% to 99.3% on 47 questions, and scored 100% on 2 held-out sets of 20
  • Blocked 22 of 22 SQL write attempts with a sqlglot guard, an LLM judge and a read-only PostgreSQL role
  • Added an Open-Meteo to PostgreSQL ETL agent with human-approved, hash-checked loads. Weather-query accuracy went from 0 of 12 to 11 of 12
  • Cut billed input tokens per question by ~59% with prompt caching, and got follow-ups right in 32 of 32 chats
  • Wrote a 59-question eval harness that scores execution accuracy and LLM-as-a-Judge answers

The live demo runs in demo mode: SQL questions only, a read-only database user and 15 questions per visit. The ride data is synthetic. The app sleeps when idle, so the first visit may need a moment to wake it.

Stack Python, LangGraph, LangChain, Claude, PostgreSQL, sqlglot, pandas, Pydantic, Streamlit

Data quality monitoring

Pricing Data Quality Monitor

Every weekday a GitHub Action loads end-of-day prices for 30 large-cap stocks and the Treasury yield curve from two publishers, runs 16 data quality checks, and writes an HTML report of every flag.

Yahoo Finance, Treasury, FRED→SQLite→16 SQL and statistical checks→HTML report + issues CSV→plant errors, score recall and precision

  • Built 16 checks in SQL and Python, from gaps-and-islands stale-price detection to robust z-scores on market-adjusted returns, across 30 stocks and 14 Treasury tenors
  • Compared the yield curve from two publishers, Treasury and FRED, and flagged any tenor where they differ by more than 2 bp
  • Planted 130 known errors in real data from Jan 2023 to Nov 2026 (29,310 price rows, about 23,800 yield rows): the checks caught 129 (99.2% recall) at 97.7% precision, with 3 false alarms
  • Every caught error was flagged by the check built for its type; the one miss was a small yield spike, likely on a bill tenor FRED doesn't publish

Stack Python, SQL (SQLite, window functions), pandas, NumPy, matplotlib, pytest, GitHub Actions

RAG and LoRA on public tissue images

Multimodal LLM for Cancer Pathology Classification

Classifies four tissue types two ways: a RAG pipeline over image captions, and a fused image-plus-text model tuned with LoRA.

tissue image→BLIP caption→FAISS index→GPT-3.5 names the tissue type

  • Built a RAG pipeline that captions tissue images with BLIP, indexes them in FAISS and classifies 4 tissue types with GPT-3.5
